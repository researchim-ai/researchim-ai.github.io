# Drawing examples

These are original generated TRAIN references from the cad-env mechanical pilot,
not manufacturer drawings or model predictions. See provenance.json for source
part IDs and file hashes. Both profiles are drafts; full conformance is unconfirmed.

Technical text is rendered as outlines from osifont, by Zefram Cochrane /
hikikomori82 and contributors. The selected font is LGPLv3 with a font exception
for documents. Upstream: https://github.com/hikikomori82/osifont
Pinned commit: afbc9134f90733eb5eea0a1c70c56a6d5dd5b758.
No font files are bundled. Referenced bearing boundary dimensions are attributed
to NSK in the article; the generated housing is an original nominal design.
