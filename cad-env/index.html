01 / CAD BACKENDS
Two engines.

FreeCAD is our main environment. CadQuery runs the same basic actions through its own geometry backend. We execute every reference solution before adding it to a dataset.

WHAT THE AGENT CAN DO
The shared tool set covers basic construction and parameter edits. The advanced solid-modeling probes use a separate interface. Assembly workflows and unrestricted CAD APIs are outside the current agent benchmark.

04 / TRAINING
Learning to finish the job.
We train on reference actions, then inspect the model’s own runs. Missing features and failed tool calls tell us which examples the next dataset needs.
01 / REFERENCE SOLUTIONS
Supervised fine-tuning
A drawing, the current CAD state and the next action. LoRA adapts the language model and selected vision layers; the loss is calculated on the answer tokens.
 USED IN COMPLETED RUNS
02 / RECOVERY
Recover after a mistake
Collect failed steps from real model runs and verify the corrected continuation in FreeCAD. The collector works, but coverage is still small.
 SMALL PILOT DATASET
03 / REINFORCEMENT LEARNING
Reward from the CAD result
Single-action visual GRPO has been tested. We have not established a quality gain from it, and full multi-step policy-gradient training is not implemented yet.
